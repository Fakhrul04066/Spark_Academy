# Spark Academy

React + Vite conversion of the supplied Bengali landing-page demo.

Run: `npm install` then `npm run dev`. Production: `npm run build`.

Includes course/grade filters, mobile navigation, FAQs and modal forms. Forms are demo-only; no personal data or credentials are sent or stored. No backend, payment or authentication service is connected. Google Fonts require internet; system fonts are the fallback.


Branding: Spark Academy — Smart Learning Platform. Emerald Green, Deep Navy and White. SVG logo assets are in public/.

This checkout contains only the landing-page prototype; the full platform, dashboards, mobile app, email services and database are not present. No database operations were performed.
